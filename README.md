# レシート家計簿

レシート画像をアップロードすると、Claude API（Claude Haiku 4.5）が商品名・金額・日付を読み取り、カテゴリ別に自動分類して家計簿に記録する Web アプリです。

## 主な機能

- レシート画像のアップロード（ドラッグ＆ドロップ対応）と Claude による自動読み取り
- 読み取った商品名・金額・日付・カテゴリの確認と修正
- 読み取れなかった項目の要確認表示（黄色）と手動修正、読み取りに失敗したレシートの手入力登録
- カテゴリ（食費・外食・日用品・交通費・衣服・美容・医療・健康・趣味・娯楽・その他）への自動分類
- 月ごとのカテゴリ別円グラフ・直近 6 か月の月別棒グラフ（Chart.js）
- 登録データはブラウザのローカルストレージに保存（リロードしても残ります）

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `client/` | フロントエンド（React + Vite + Chart.js） |
| `server/` | バックエンド（Node.js + Express）。Claude API を呼び出す |

API キーはバックエンドだけが保持し、ブラウザには渡しません。開発時は Vite が `/api` へのリクエストをバックエンド（ポート 3001）に転送します。

## セットアップ

Node.js 20 以上が必要です。

```bash
# 依存パッケージのインストール
npm run install:all

# API キーの設定（.env は .gitignore 済み）
cp .env.example .env
# .env を開き、ANTHROPIC_API_KEY に Claude API のキーを設定する

# 開発サーバーの起動（バックエンドとフロントエンドを同時に起動）
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

## 注意事項

- 家計データはブラウザのローカルストレージにのみ保存されます。ブラウザのデータを消去すると記録も消えます。
- レシート画像はサーバーに保存されず、読み取り後に破棄されます。
